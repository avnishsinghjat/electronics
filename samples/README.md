# Sample files

| File | Purpose |
| --- | --- |
| `boq-template.csv` | The standard BOQ CSV template to give clients (imports with no mapping). |
| `boq-clean.csv` | Clean 15-line controller BOQ using parts from the seed data (imports with no errors). |
| `boq-clean-rev-b.csv` | Revision B of the same BOQ: one line added, one removed, one quantity change, one part substituted. Import after `boq-clean.csv` and compare A vs B. |
| `boq-clean.xlsx` | `boq-clean.csv` as Excel, with a title row above the header. |
| `boq-messy.csv` | Windows-1252 file with title rows and non-standard headers, containing every validation error and warning type (see `docs/user-guide/boq.md`). |
| `boq-semicolon-utf8bom.csv` | European export: `;` delimiter, UTF-8 BOM, decimal comma, a non-countable unit (metres). |
| `kicad-bom.csv` | `kicad-cli sch export bom` output with MPN/Manufacturer fields and a DNP line. |
| `boq-2000.csv` | 2,000 distinct lines for the import performance test. |

`boq-clean.xlsx` and `boq-2000.csv` are generated by `scripts/gen_sample_boqs.py`.
